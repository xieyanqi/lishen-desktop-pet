# 小黎原生版 · 可动交互试用版 0.3

作者：Astrizaynie。Windows x64，C++17 + GDI+ + Raw Input。独立实现，不需要 Rainmeter，不联网、不设置开机启动、不保存输入内容。

## 怎么试用

下载试用压缩包并解压，双击 `LiShen.exe`。这是单文件便携程序，无需安装；可以只保留或移动该 EXE，HTML 与说明书都是可选文件。先退出原来的 Rainmeter 小黎，避免桌面上出现两个。鼠标移动时观察视线，切到记事本打字时观察双手，停顿后等待推眼镜动作。按住人物即可拖动；右键人物或系统托盘图标打开菜单，可以立即预览推眼镜，并切换四分之一速度慢放。

开启鼠标穿透后，单击托盘图标或按 Ctrl+Alt+Shift+L 恢复操作。快捷键冲突会提示使用托盘。

不想运行程序时，可先双击压缩包内的 `互动预览.html`。移动鼠标观察眼睛，在页面中打字或点击按钮观察动作，可慢放、暂停或拖动进度条逐帧检查。预览页只接收当前页面的按键，不感知其他程序的打字。

## 已实现与限制

- 眼睛独立水平／垂直跟随，平滑过渡；周期眨眼与轻微呼吸。
- 全局按键仅触发双手交替按键，手指与对应键帽同步下沉。响应有上限，不按输入文字绘制，也不记录文字和键码。
- 停顿后推眼镜，手指先接触镜框，再推起、扶住、回稳、收手；重新打字时先收完当前手势，再返回工作动作。
- 透明置顶窗口、自由拖动、透明区域不挡点击、鼠标穿透、托盘恢复。
- 人物是程序重新绘制的简化原型，画风尚未定稿；不是原插画的分层动画。
- 工作／休息计时、今日计划、语录、报告、下雪、投喂菜单和四边隐藏尚未迁移。菜单中的“休息形象预览”只改变衣服配色。
- 通过 Windows x64 交叉编译、动作状态与接触几何测试、HTML 控制逻辑测试；尚未在 Windows 桌面实际运行验收。不能视为正式版，不会读取或修改旧版记录。
- 程序未签名，Windows 可能拦截；请勿为试用关闭系统安全保护。

## 构建与测试

Windows 安装 Visual Studio 2022 的“使用 C++ 的桌面开发”和 CMake，在本目录执行：

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

运行 `build\Release\LiShen.exe`。无第三方运行时要求。Linux 可用 MinGW 或 Zig 交叉编译；状态测试只依赖 C++17 标准库。`tests/preview.cpp` 用与桌面版同一套人物绘制函数输出 SVG 动画帧，预览页使用这些帧展示动作。

当前优先验收输入响应、动作观感、拖动、多屏和显示缩放。画风与交互确认后，再迁移现有功能及导入旧数据。

## v0.3 验收重点

1. 打字时，手指落到键帽上，按下和释放都有过渡，对应键帽同步下沉。
2. 推眼镜时，抬手阶段镜框不提前移动；接触后镜框上移 6 个绘制单位；扶镜期间指尖与镜框保持同一接触点；放稳后才收手。
3. 肩膀、手肘、手腕分开计算，手臂沿外侧抬起，避免穿过脸部。支持正常与四分之一速度检查。
4. 当前 EXE 内含人物绘制、程序说明信息和普通用户权限清单，没有外部素材依赖。Windows 构建配置使用 MSVC 与静态 C++ 运行库；这里提供的试用 EXE 使用 Zig 交叉编译。两种构建均不等同于可信签名，不能承诺绕过智能应用控制。

生成 HTML 预览：先编译并运行 `tests/preview.cpp`，把输出通过标准输入传给 `tools/build_preview.py`。预览帧来自桌面程序同一套绘制与接触计算；浏览器里的打字节奏是演示循环，桌面版按实际按键触发。
