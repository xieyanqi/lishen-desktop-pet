# 小黎原生版 · 可动交互试用版 0.2.1

作者：Astrizaynie。Windows x64，C++17 + GDI+ + Raw Input。独立实现，不需要 Rainmeter，不联网、不设置开机启动、不保存输入内容。

## 怎么试用

下载试用压缩包并完整解压，双击 `LiShen.exe`。先退出原来的 Rainmeter 小黎，避免桌面上出现两个。鼠标移动时观察视线，切到记事本打字时观察双手，停顿后等待推眼镜动作。按住人物即可拖动；右键人物或系统托盘图标打开菜单，可以立即预览推眼镜。

开启鼠标穿透后，单击托盘图标或按 Ctrl+Alt+Shift+L 恢复操作。快捷键冲突会提示使用托盘。

不想运行程序时，可先双击压缩包内的 `互动预览.html`。移动鼠标观察眼睛，在页面中打字或点击按钮观察动作。预览页只接收当前页面的按键，不感知其他程序的打字。

## 已实现与限制

- 眼睛独立水平／垂直跟随，平滑过渡；周期眨眼与轻微呼吸。
- 全局按键仅触发双手交替运动。响应有上限，不按输入文字绘制，也不记录文字和键码。
- 停顿后推眼镜；重新打字时先收完当前手势，再返回工作动作。
- 透明置顶窗口、自由拖动、透明区域不挡点击、鼠标穿透、托盘恢复。
- 人物是程序重新绘制的简化原型，画风尚未定稿；不是原插画的分层动画。
- 工作／休息计时、今日计划、语录、报告、下雪、投喂菜单和四边隐藏尚未迁移。菜单中的“休息形象预览”只改变衣服配色。
- 通过 Windows x64 交叉编译和平台无关状态测试；尚未在 Windows 桌面实际运行验收。不能视为正式版，不会读取或修改旧版记录。
- 程序未签名，Windows 可能拦截；请勿为试用关闭系统安全保护。

## 构建与测试

Windows 安装 Visual Studio 2022 的“使用 C++ 的桌面开发”和 CMake，在本目录执行：

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

运行 `build\Release\LiShen.exe`。无第三方运行时要求。Linux 可用 MinGW 或 Zig 交叉编译；状态测试只依赖 C++17 标准库。`tests/preview.cpp` 用与桌面版同一套人物绘制函数输出 SVG 动画帧，预览页使用这些帧展示动作。

当前优先验收输入响应、动作观感、拖动、多屏和显示缩放。画风与交互确认后，再迁移现有功能及导入旧数据。
