# 黎深桌宠

一个《恋与深空》黎深同人桌宠。工作时，捧杯的白黎陪你计时，鼠标移过去他会随机说一句话。休息时换成黑黎，可以给他投喂甜食。

## 第一次安装

适用于 Windows 11 或 64 位 Windows 10（1903 及以上）。整个过程用鼠标操作即可。

1. 打开 [Rainmeter 官网下载页](https://www.rainmeter.net/changes-5.0/)，点击 **Download Rainmeter 5.0 RC2**。如果打开的是 GitHub 发布页，在 **Assets** 里选 `Rainmeter-5.0.0.5363-RC2.exe`。运行安装文件，选 **Standard installation（标准安装）**。如果想让黎深随电脑启动，勾选 **Launch Rainmeter on startup（开机启动 Rainmeter）**。
2. 打开 Rainmeter。点击本页上方的 **下载黎深桌宠安装包**，在电脑的「下载」文件夹里双击 `LiShen-Desktop-Pet.rmskin`，点 **Install（安装）**。
3. 回到桌面，在右下角找黎深。找到了就可以拖到喜欢的位置。想立刻看一次提醒，右键黎深 → **休息设置…** → **现在休息**。


## 今日计划与每轮工作

每天第一次打开桌宠，白黎会问「今天打算做哪三件事？」。点击事项填写，按 **Enter** 保存。可以留空，之后通过右键的 **计划与计时…** 随时补充。右侧的圆圈可以标记完成，已有的当日计划会保留，也可以把昨天没完成的事项带过来。

保存今日计划后，选择接下来要做的事。可以点击今日计划中的一项，或自己填写本轮任务，然后点 **开始**。填写之前会等待，点开始才累计工作计时。暂时关掉填写面板也可以，再右键打开即可继续。

每轮休息结束时，浅蓝遮罩和下雪会继续保留，并再次询问本轮想做什么。选好或填写至少一句任务，再点 **开始**，才会收起雪景并启动下一轮工作倒计时。关闭面板或留空都不会开始计时，可以右键 → **计划与计时…** → **本轮工作** 继续填写。可以继续上一件事，或另选任务。同名事项在报告里会合并统计。工作到点弹出提醒卡后，可以点 **这件事已完成** 记录完成状态，再点 **开始休息**。需要继续做就直接开始休息，下一轮再选择该事项。

鼠标靠近白黎或黑黎时，仍可以查看语录或投喂。点击倒计时气泡里的 **今日三件事**，会在小黎左侧展开计划与本轮任务，再点一次收起。鼠标靠近或移开时不会自动开关计划面板；点击计划文字可以打开编辑面板。

## 分组操作面板

右键小黎的自定义皮肤动作中，有四个分组功能入口和一个「一键隐藏黎深」。分组面板顶部也可以直接切换。

| 入口 | 可以做什么 |
| --- | --- |
| **计划与计时…** | 编辑今日三件事、选择本轮任务、开始／暂停／继续、提前完成、现在休息 |
| **语录设置…** | 切换三种语录模式、编辑自己的语录、投稿、开启／关闭他人投稿 |
| **休息设置…** | 修改工作和休息时长、修改休息项目、现在休息 |
| **报告与记录…** | 导出日／周／月或指定日期报告、导出 CSV、按日期范围清除记录 |

## 修改时长与休息项目

右键 → **休息设置…** → **设置工作和休息时长**。记事本默认工作 **45 分钟**、休息 **5 分钟**。改等号右边的数字，可填 **1 到 999** 的整数，按 **Ctrl + S** 保存。

同一面板中的 **设置休息项目** 可以编辑休息时想做的事情，每行一项。保存后，下一次提醒会随机选择其中一项。留空时使用示例项目。

工作到点时，主屏幕上方会出现休息提醒卡，桌面开始下雪，全程静音。点 **开始休息**，黑黎会出现并开始倒计时，雪会继续下。归零或点 **结束休息** 后，进入下一轮工作任务填写。点 **延后 5 分钟**，提醒卡和雪会一起收起，五分钟后重新出现。每轮最多延后三次，按钮会显示已用次数。第三次延后的五分钟结束后，会自动开始休息倒计时并下雪。休息结束后，延后次数清零。

## 收到屏幕边缘

把小黎拖到屏幕的上、下、左、右任意一边再松开鼠标，就会自动收到对应边缘。也可以右键 → **自定义皮肤动作 → 一键隐藏黎深**，自动选最近的一边。

四边都有专门的白黎探身动作，身体和手臂会一起显示。上沿采用单手抓住上方边缘的姿势。

- 常态为眨眼探头的静态造型。
- 鼠标靠近时，换成多探出身体、向你挥手的造型。
- 鼠标移开，恢复常态造型。
- 左键点击小黎，恢复完整桌宠。拖边隐藏后，会回到拖动前的位置。
- 工作、休息、延后五分钟和本地记录照常运行，休息提醒和下雪仍会出现。

## 陪伴报告与记录

右键 → **报告与记录…**，选择今天、本周、本月报告，或填写开始与结束日期后导出所选日期报告。日期格式为 **YYYY-MM-DD**，例如 **2026-11-19**。一周从周一开始，本周、本月统计至今天。

报告在浏览器打开，显示事项累计工作计时时长、每日时长、每日计划完成状态及每轮记录。点击 **打印／保存为 PDF**，在打印窗口选择保存为 PDF，即可保留一份报告。

**导出所有工作记录与计划（CSV）** 会生成两份文件，分别记录每轮工作和每日三件事，可以用 Excel 打开。文件位于 Rainmeter 设置文件夹，导出后会打开该文件夹。

需要清理时，点 **清除本地记录…**，选择今天、本周、本月、全部日期或已填写的日期范围，再点 **确认清除**。可以先导出备份。已经导出的 HTML、PDF、CSV 文件由你自行保留或删除。

工作计时只在点开始后、桌宠运行且未暂停时累计。休息、暂停、电脑睡眠或关闭桌宠期间不累计。记录约每 5 秒保存一次，正常关闭时也会保存。意外断电可能丢失最近约 5 秒的计时。重开会保留已有记录，等待你点开始继续。

记录保存在本机 Rainmeter 设置文件夹中的 `LiShen-Journal.txt`，另有上一份保存状态的备份。报告统计的是工作计时器运行时长，完成状态由你自己标记。无需注册账号。

## 悬停语录与投喂

- **工作时**，把鼠标移到白黎身上，会显示带蓝色雪花的工作倒计时气泡，并按你选的语录模式随机显示一句。等气泡关闭后再次靠近，可以看到另一句。
- **休息时**，把鼠标移到黑黎身上，他的右上方会出现带蓝色雪花的小菜单。每次打开会从 26 种甜食里随机挑出三种，候选池里没有胡萝卜相关甜食。点选其中一种后，黑黎会切换到吃甜食的表情约 10 秒，菜单会显示一个随机颜文字（共 56 种）。休息计时仍在运行，最后 10 秒内停止接收投喂。

鼠标移出桌宠和气泡后，语录气泡和投喂菜单会保留约 10 秒。鼠标移回来会取消关闭。投喂后移开鼠标，颜文字也会保留到这 10 秒结束。工作与休息状态切换时，气泡会随状态更新。

## 设置语录与投稿

最初的 87 条语录整理自游戏里黎深的**牵绊度语录**和一些**卡面经典语录**。这份整理肯定还有遗漏，请大家多担待，也欢迎家茉来补充。

右键黎深，打开 **语录设置…**：

- **仅使用我的语录**。在记事本里每行填一句，按 **Ctrl + S** 保存。第一次添加至少一句后，白黎就只会抽取你写的句子。
- **恢复默认语录**。一键回到最初的 87 条，自己写过的句子仍保存在电脑上。
- **在默认语录上补充我的语录**。白黎会从默认语录和你写的句子里抽取。这里和「仅使用我的语录」打开的是同一份记事本。
- **开启／关闭他人投稿语录**。在「在默认语录上补充我的语录」的模式中，可以决定是否让白黎也抽取已审核收录的投稿。
- **向开发者投稿黎深语录**。打开中文说明，点 **打开中文投稿表单**，也可以直接进入[中文语录投稿表单](https://github.com/xieyanqi/lishen-desktop-pet/issues/new?template=share-quote.yml)。

编辑本机语录时，以 `#` 开头的行是说明。编辑本机语录无需 GitHub 账号，公开投稿需要登录 GitHub。

1. 把想投稿的句子粘贴到 **我想分享的语录**，每行一句。
2. 点右下角绿色的 **Create（提交）**。标题已经填好，右边的选项可以直接略过。

投稿由开发者 Astrizaynie 审核。审核通过、收录到新版，并且用户安装新版并开启他人投稿语录后，桌宠才会抽取该句。

提交后，句子和你的 GitHub 用户名会公开显示。

## 开机启动与性能

新版每秒更新一次，语录文件等到第一次悬停时才读取。桌宠本身在本机运行，点击投稿入口时才会打开 GitHub。

在 Windows 按 **Ctrl + Shift + Esc**，打开 **任务管理器 → 启动应用**，可以查看 Rainmeter 的「启动影响」。如果你希望 Rainmeter 完全不参与登录时启动，右键它选 **禁用**。以后需要桌宠时，从开始菜单搜索并打开 **Rainmeter**。如果它已经在运行，关闭自启不会把它关掉。[微软官方操作说明](https://support.microsoft.com/en-gb/windows/experience/startup-boot/configure-startup-applications-in-windows)

## 遇到问题

| 情况 | 怎么处理 |
| --- | --- |
| 点下载链接后没开始下载 | 打开 [安装包文件页](https://github.com/xieyanqi/lishen-desktop-pet/blob/main/LiShen-Desktop-Pet.rmskin)，点击文件右上角的下载图标 **Download raw file**。 |
| 双击安装包后，Windows 问用什么打开 | 先完成 Rainmeter 的标准安装，再双击以 `.rmskin` 结尾的文件。 |
| 安装完成，桌面上没有小人 | 点任务栏右下角的 Rainmeter 雨滴图标。在 **Manage（管理）→ Skins（皮肤）** 里展开 **LiShen**，选中 **LiShen.ini**，点 **Load（加载）**。看不到 LiShen 时，先点 **Refresh all（刷新全部）**。 |
| Rainmeter 提示版本太旧 | 装 [Rainmeter 5.0 RC2 或更新版本](https://www.rainmeter.net/changes-5.0/)，再双击桌宠安装包。 |
| 想关掉黎深 | 右键小人，选择 **Unload skin（卸载皮肤）**。想再用时，从 Rainmeter 的管理窗口重新加载 **LiShen.ini**。 |
| 安装包还要留着吗 | 确认黎深已出现在桌面后，可以删掉「下载」里的安装包。日常运行需要保留 Rainmeter 和已经安装的桌宠皮肤。 |
